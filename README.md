Дання инструкция для роботов TurtleBro, созданного для изучения ROS1

Образовательный робот _**TurtleBro**_ предназначен для изучения современной робототехники на примере мета‑операционной системы Robot Operating System (ROS), работающей в среде Linux.

Учебные материалы для самостоятельного изучения ROS доступны на портале [http://learn.voltbro.ru](http://learn.voltbro.ru).

Также вы можете прочитать книгу "[Введение в ROS](http://docs.voltbro.ru/starting-ros/)".

Робот разработан и поддерживается проектом "[Братья Вольт](http://www.voltbro.ru)".
